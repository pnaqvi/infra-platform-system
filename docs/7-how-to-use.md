# How to Use Infra-Platform-System

*Document 4 of 4 · v1, August 2026. Commands and rhythms.*

## Daily

- **Pulse:** "run my pulse" — due/overdue commitments, fired revisit triggers, aging positions, cadence artifacts due or missing. Two minutes; the system's anticipation pass.

- **Think:** "quick take on X" / "help me think through X" → advisor (strategy), org-advisor (people/structure), metrics-advisor (measurement), vendor-eval (vendors). Say "spin up the platform team" for the full brainstorm.
- **Prep:** "prep me for <meeting>" → the one-page prep from what the system already knows; "here's how it went" captures the aftermath.
- **Ship:** "announce X" / "make the case to <audience>" → comms; "make this exec-ready" / "review before I send" → exec-writer; "this is what I sent" teaches it your voice.
- **Evidence in:** "synthesize these interviews" / "build the pain map" → research, every theme verbatim-cited.
- **Capture:** "remember this: …" — one sentence is enough; the system structures it, you confirm once.
- **File:** "store this as a tech plan / project plan / strategy doc" — named, registered, committed. Share source material ("file this in reference") and it lands in the indexed reference library.
- **Find:** "what did we decide about X" · "where is the Y plan" · "what's my position on Z".

## Monthly

- "draft the <month> plan" → objectives, milestones (ledgered on commit), carry-forwards, capacity, risks.
- "update monthly status" → plan scorecard, metric actuals to the snapshot, unplanned work, learnings — updatable through the month.
- "start the <month> MBR" → composed from the plan, status, snapshot, and ledger; renders md/deck/doc; ledgers new commitments when you say it's sent.
- "run memory maintenance" → inboxes merged, integrity checks, archives rolled, state report.

## Quarterly

- "prep quarterly planning" / "build next year's budget" / "rebalance the portfolio" → portfolio-planning (the analysis); then
- "draft the <quarter> plan" / "update quarterly status" / "prep the <quarter> QBR" → same plan → status → review cycle at quarter scale: commitment scorecard from the ledger, strategy check-in, portfolio view, next-quarter commitments.
- "review my open platform decisions" → have revisit triggers fired; calibration honestly under small-N.
- "run system maintenance" → friction-log review, consolidation pass, profile re-confirmation, CHANGELOG entry.

## As needed

- "what's changed that bears on my anchors/decisions" → field brief (only intersections with your recorded thinking).
- "make this an exec one-pager / board memo" → convert mode.
- "export my <topic> positions for <audience>" → sanitized extract.
- "help" / "which skill handles X" / "what version am I running" → core help mode.

## After install / after a release

- **"initialize the infra-platform system"** — the one command that takes a fresh install to fully initialized: shakedown, fact-sheet, bootstrap interview, standing meetings, risk register, open the period, first pulse. Full (~90 min) or express (~30 min); resumable.
- After releases: "run the shakedown" re-validates; keep the fact-sheet confirmed.

## The habits that make it compound

1. Capture in the moment — one line beats a perfect entry never written. 2. Let reviews open from the ledger, not memory-of-meetings. 3. Answer the panels' checkpoint questions — they're the highest-leverage minutes in a team session. 4. When the system mis-fires, say "log that as friction" — it's how the system improves.
