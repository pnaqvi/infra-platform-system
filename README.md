# Infra-Platform-System

The standalone operating system for Parvez's multi-year cloud infrastructure platform program (~1,000 engineers): advisors, memory, a document workspace, and the MBR/QBR review cadence. Fully independent of any other skill system.

Install: `bash install.sh` (see skills/infra-platform-core/references/install-guide.md).
First run: "bootstrap my platform positions", then drop source docs into the workspace inbox and say "file my workspace inbox".
Help anytime: "help — what can this system do?"
